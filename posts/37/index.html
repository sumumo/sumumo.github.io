Postman 请求自动 SM2、SM4 加解密

发表于 2024-06-13 阅读次数：

添加新包

  1. 打开 HTTP 请求、集合、或者文件夹，然后选择 Scripts 选项。

  2. 选择 Pre-request 或 Post-response 选项。

  3. 打开代码编辑器右侧的窗口，然后选择 Open package library。

SM2 加解密

  1. 选择 New package。
  2. 输入包名：sm2。
  3. 将代码粘贴到窗口中。
  4. 选择 Create。

SM4 加解密

  1. 选择 New package。
  2. 输入包名：sm4utils。
  3. 将代码粘贴到窗口中。
  4. 选择 Create。

添加环境变量

  1. 选择右侧按钮，选择 Add。
  2. 在打开的窗口中添加变量 sm4key、sm2key 内容为 SM4 密钥、SM2 密钥。
  3. 选择 Save 。
  4. 右上角选择设置的环境变量。
